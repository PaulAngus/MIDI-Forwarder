# MIDI Forwarder 1.0.2

Released 19 October 2026.

The server now validates legacy ports against the same catalog used by discovery and opening. This accepts the actual Windows 10 input name, such as `FM9 MIDI In [0]`, instead of rejecting it because WinMM reports `FM9 MIDI In`. Explicit port selection and unique-device checks remain in place.

Four focused discovery checks passed. On Windows 10 Home build 19045, the production client and corrected server each completed two bidirectional TCP-to-FM9 query/reply rounds using the existing FM9, firmware 12.00, without loopMIDI. Existing MIDI/PnP inventories and observed preset/scene state were unchanged. These checks used local TCP peers; they do not establish two-machine network behavior or an application-facing virtual-device workflow.

The Windows 10 deployment uses the self-contained server. Existing offline Test Lab agents and scheduling restrictions remain unchanged. No driver, additional system package, Windows feature or virtual MIDI port is installed or created. The full suite is not rerun for this patch.
