# MIDI Forwarder 1.0.8

Publishes the latest Client/Server source, including the native application names,
with the exact clean MIDIHelperLibrary 0.3.14 packages and producer provenance.
The normal Windows compressed self-contained single-file and Apple Silicon Mac
publishers are retained. Windows ReadyToRun remains disabled; fresh short build
intermediates keep publication independent of old outputs. Existing settings and
endpoint configuration are preserved by file-only distribution.

No tests or application launches are part of this publication. Package/signature
inspection does not qualify native MIDI, hardware or end-user workflows. Later
acceptance requires an immutable shared-midi-change plan, all four core
beneficiaries, genuine inputs, paired dispatch and verified restoration.
