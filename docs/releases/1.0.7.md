# 1.0.7

Client and Server use shared MIDI helper 0.3.13. It fixes a streaming Apple RTP
packet decoding failure seen when FM9-Edit and Preset Maestro share a connection,
reports malformed packets immediately, and releases sockets after receive faults.

The normal Client/Server publish paths and application configuration are unchanged.
Native coexistence, real full/names-only scans and reconnect acceptance run through
the cross-platform platform, using the same unchanged normal installed candidates.
No general acceptance result is claimed from the diagnostic packet capture.
